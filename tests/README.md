# Тестовые скрипты Docling OCR API

## Обзор

Папка `tests/` содержит автоматизированные тесты и вспомогательные скрипты для тестирования функциональности API.

## Структура

### Официальные тесты (pytest)
- `test_health.py` - Тесты health check эндпоинта
- `test_upload.py` - Тесты загрузки файлов
- `test_pipeline.py` - Тесты пайплайнов обработки
- `test_archive_upload.py` - Тесты загрузки архивов
- `conftest.py` - Конфигурация pytest

### Вспомогательные скрипты
- `test_api.py` - Тест стандартного пайплайна
- `test_vlm.py` - Тест VLM пайплайна
- `test_final.py` - Комплексный тест обоих пайплайнов

## Запуск тестов

### Официальные тесты
```bash
# Все тесты
pytest

# Конкретный тест
pytest test_health.py

# С подробным выводом
pytest -v
```

### Вспомогательные скрипты
```bash
# Тест стандартного пайплайна
python tests/test_api.py

# Тест VLM пайплайна
python tests/test_vlm.py

# Комплексный тест
python tests/test_final.py
```

## Требования

- Запущенный контейнер Docling OCR API
- Доступные тестовые файлы в `d:\codding\ai\_RAG\docs\`
- Настроенный .env файл с переменными окружения

## Примечания

- Тестовые скрипты используют реальные документы для тестирования
- VLM пайплайн требует действительного API ключа OpenRouter
- Все переменные окружения автоматически загружаются из .env файла
